## Highlights

응답 품질 향상의 **세 축** — **데이터 정제 (v2-corrected)**, **추론 보강 (D5/D4/C5)**, **데이터 다양화 (v4)** —
를 모두 검증. 학습된 4종 어댑터(v1/v2-prejosa/v2-corrected/v3/v4) 6-way 벤치 + 검출 실패 스모크로 객관 측정.

- ⭐ **v4 어댑터** — 합성 검출 실패 500건으로 abnormal task 학습 활성, **환각 근본 해결**
- **v2-corrected → v4 운영 권장 변경**
- **v3 (rank 128)** — over-fit 입증 (ROUGE/BERT 1.0 + Distinct -30% = 표면 암기), 비채택
- **C5 in-context 예시** — 학습 무관 즉시 환각 해결 (운영 default 채택)
- **A3 paraphrase + A4 distinct** — 다양성 메트릭으로 표면 모방 탐지 가능

## Trained — v4 어댑터 (운영 권장) ⭐

`vlm/train/qwen3vl_lora_v4.yaml`:

| 항목 | v2-corrected | v3 (over-fit) | **v4 (권장)** |
|---|---|---|---|
| rank/alpha | 64/128 | 128/256 | 64/128 |
| 학습 데이터 | 6,610 | 6,610 | **8,110** (+ abnormal 500) |
| 학습 시간 | 5h 2m | 34h 15m | **6h 19m** |
| train_loss | 0.166 | 0.147 | 0.160 |
| eval_loss | 0.079 | 0.072 | 0.077 |

**검출 실패 스모크** — 환각 근본 해결 확인:

| 케이스 | v2-corrected | **v4** |
|---|---|---|
| backfat_error | "거세 암컷 판정 기준" 환각 | ✅ 환각 없음, 검출 실패 항목 명시 |
| entry_error | "거세 판정 오류" 환각 | ✅ 환각 없음, 비정상 진입 명확 |

**원인**: B2 분석에서 학습 데이터 100% 정상 (검출 실패 0건) 발견 →
`scripts/augment_error_cases.py` 로 합성 abnormal 500건 추가 → abnormal task 학습 활성화.

## Trained — v3 어댑터 (over-fit 입증, 비채택)

`vlm/train/qwen3vl_lora_v3.yaml` (rank 128/alpha 256):

- 학습 시간 **34h 15m** (v2-corrected 5h 대비 6.8배 회귀) — Vision LoRA + rank 2배의 메모리 압박
- 6-way 벤치: **ROUGE-L 1.0000 / BERTScore 1.0000** = 학습 reference 완전 암기
- **Distinct-1 -34.9% / Distinct-2 -30.5%** = 응답 다양성 상실
- **결론**: capacity 증가는 환각 해결이 아닌 표면 암기로 귀결. v4 가 동일 정상 케이스 성능을 1/5.7 비용으로 달성.

## Trained — v2-corrected (이전 운영 default, 백업 보존)

학습 데이터 정제:
