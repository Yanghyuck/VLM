## Highlights

YOLO 도체 분석 시스템 `thema_pa_VLM` 이 측정 결과를 VLM API 로 직접 호출해
한국어 판정 리포트를 받아 저장하는 운영 흐름을 완성했습니다.

- **thema_pa_VLM ↔ VLM 브릿지** — `SendVLMReport` 실 네트워크 호출 + 추론 + 저장 검증
- **lifespan warm-up** — FastAPI 첫 호출 cold-start **128.9s → 20.5s (6배 가속)**
- **E2E 4/4 PASS** (warm-up + timeout 240 적용 후, 평균 25.5초/req)
- **이미지 경로 자동 매칭** — AI/ORI 패턴, `result_image_path` 자동 채움

## Added — thema_pa ↔ VLM 브릿지

- 연동 대상 폴더를 `thema_pa` → `thema_pa_VLM` 으로 전환 (원본 미수정 사본 사용)
- `scripts/export_from_db.py` — 이미지 경로 자동 매칭 (AI / ORI 패턴)
- `tests/test_thema_pa_vlm_bridge.py` — 통합 테스트 5건 (`THEMA_PA_ROOT` 의존)
- `storage/vlm_reports/` — 호출 결과 누적 (gitignore + .gitkeep)
- `scripts/test_e2e_thema_pa_bridge.py` — 실 네트워크 + 추론 + 저장 E2E

## Added — API 안정성 (lifespan warm-up)

- `vlm/api/server.py` — `lifespan` 단계에서 더미 추론 1회 수행 (cold-start 제거)
- `config.api.warmup_on_startup` 플래그
- `config.api.inference_timeout_sec` 기본 180 → 240 (복잡 입력 여유)

## Changed

- `requirements.txt` — `numpy<2.3` 핀 (opencv-python 4.12 호환)
